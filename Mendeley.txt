Step-by-step method of creating the testing dataset:
1. The Gemini LLM should be installed.

2. Gemini API key should be stored as a secret key and should not in any way be revealed in public.

3. Two lists of possibly the Kaggle symptoms and Mendeley symptoms should be built.

4. The two lists will be given to Gemini.

5. The mapped symptoms must be manually checked at last.

6. The 131 symptoms table will finally be built for testing.



How to integrate Gemini LLM into Jupyter Notebook?

1. Install the google-genai library for Gemini. 

2. Go to Google AI studio, create an API key and copy the API key.

3. Remember not to push the API key containing file into Github or make the keys be in public view.

4. Store the API key in a file that is in the same folder as the notebook.
